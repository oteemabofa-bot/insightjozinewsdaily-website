# Insight Jozi News Daily

This repository contains a lightweight static website for the Insight Jozi News Daily publication, designed to work with Netlify static hosting.

## Project structure

- `index.html` — homepage markup
- `styles.css` — site styling and responsive layout
- `script.js` — small interaction for the mobile menu and newsletter form
- `netlify.toml` — Netlify deployment configuration

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server.

## Deploy on Netlify

1. Import this repository into Netlify.
2. Use the default settings for a static site.
3. Publish the site.

The site is ready for editing directly from the GitHub repository.
